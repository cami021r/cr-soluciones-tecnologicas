# C&R Soluciones Tecnológicas

Plataforma web de gestión empresarial para el sector de soporte técnico
y redes en Bogotá. Elimina la informalidad mediante automatización digital.

## Stack Tecnológico

- **Backend:** Python + FastAPI
- **Base de datos:** MySQL (local) / MySQL HeatWave (OCI)
- **Frontend:** React + TypeScript + Vite + Tailwind CSS
- **IA:** Claude API (Anthropic)
- **Notificaciones:** Telegram Bot API
- **Infraestructura:** Oracle Cloud Free Tier (OCI)
- **Contenedores:** Docker + Docker Compose
- **CI/CD:** GitHub Actions

## Estructura del Proyecto
cr-soluciones-tecnologicas/
├── backend/       → FastAPI + Python
├── frontend/      → React + TypeScript
├── mobile/        → React Native
├── database/      → Scripts SQL
├── docs/          → Documentación
└── .github/       → GitHub Actions
## Módulos del Sistema

1. Inventario físico con códigos QR
2. Catálogo de servicios y productos externos
3. Motor de cotización con Chatbot IA
4. Sistema de tickets y mesa de ayuda
5. Motor financiero con proyecciones
6. Dashboard administrador
7. Portal del cliente
8. App móvil
